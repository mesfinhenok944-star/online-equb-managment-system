# Online Equb Management System App

A modern, full-stack Online Equb management platform featuring a Flutter mobile frontend and a Node.js / Express / Firebase backend.

## Features
- **Multi-tier Role Management**: Super Admin, Level Admins, and Members.
- **Level-Isolated Equb Draws**: Draw history and active pools separated by target levels.
- **Weighted Fair Draw Engine**: Wheel spin selection with animated UI and sound effects.
- **Bilingual Interface**: English & Amharic UI with integrated audio notifications.
- **Firebase Sync**: Real-time user management, payment tracking, and history logs.

## Project Structure
- `online_equb/`: Flutter mobile application.
- `online_equb/backend/`: Node.js backend server.
